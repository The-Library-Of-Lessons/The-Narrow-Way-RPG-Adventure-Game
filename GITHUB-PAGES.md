# Publish this game with GitHub Pages

This package contains the complete playable nine-region browser game. Graphics, characters, maps, and animations are drawn by src/art.js and the campaign scripts. Music and effects are synthesized by src/audio.js. There are no missing PNG sprite sheets or MP3 files: those assets are generated by the included code.

## Upload

1. Extract the ZIP on your computer. Do not upload the ZIP as the website.
2. Create your GitHub repository and upload the extracted contents, keeping src/ and assets/ intact. index.html must sit directly at the repository root, alongside styles.css. Include .nojekyll if your file browser shows it.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, then main and / (root), and Save. If your default branch has a different name, select that branch.
5. Wait for GitHub's deployment to finish and open the site URL shown in Pages. No npm install or build command is needed.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Before sharing publicly

- Export your current local save from the pause menu, then import it on the published site. Browser saves do not automatically move to a different website address.
- Treat this as a playable prototype. Real Android testing, first-time-player pacing, and the two-hour gameplay target still require validation.
- Original project materials are MIT licensed. Keep LICENSE and ASSET-LICENSE.md when sharing. KJV quotations remain separately identified.
- Public source files contain the story and ending text. Avoid reading the story scripts if you want the pivotal scene to remain a surprise.
- Scripture source links need internet access when opened; gameplay does not download external graphics, audio, or libraries.
- This archive contains no player saves, development screenshots, or test output. Nothing has been published automatically.

## After deployment

Check that Begin/Continue, music after a click, map, dialogue choices, save export/import, and phone touch controls work at the actual public URL. Keep an exported save before clearing browser data or changing domains.
